# Turnover Checklist

Follow this at every clean, plus the property's own notes. 📸 = photo required.

## On arrival
- [ ] Take a walkthrough video or photos **before** touching anything 📸
- [ ] Note and photograph any damage, stains, or anything missing or left by guests 📸
- [ ] Start the first load of laundry (sheets first, then towels)
- [ ] Open windows if needed; turn on lights

## Kitchen
- [ ] Empty the dishwasher or wash, dry and put away all dishes
- [ ] Clean the stovetop, microwave (inside), countertops and sink
- [ ] Wipe cabinet fronts, appliance handles and the fridge outside
- [ ] Empty the fridge of guest food; wipe shelves 📸 (inside the fridge)
- [ ] Coffee maker emptied and cleaned
- [ ] Restock coffee, tea, sugar, dish soap, sponge, paper towels
- [ ] Kitchen done 📸

## Bathrooms
- [ ] Toilet cleaned inside, outside and behind
- [ ] Shower/tub scrubbed; no hair anywhere; glass streak-free
- [ ] Sink, counter, mirror and taps polished
- [ ] Fresh towels folded the way the reference photos show
- [ ] Restock toilet paper (2 spare minimum), soap, shampoo, conditioner, body wash
- [ ] Bin emptied, new liner
- [ ] Each bathroom done 📸

## Bedrooms
- [ ] Fresh sheets and pillowcases; bed made hotel-style (tight corners, no creases)
- [ ] Check under beds and in drawers and wardrobes for left items 📸 (under the bed)
- [ ] Dust surfaces, bedside tables and lamps
- [ ] Spare blanket and pillows in place
- [ ] Each bedroom done 📸

## Living areas
- [ ] Cushions and throws arranged as in the reference photos
- [ ] Dust all surfaces, TV stand and remotes (wipe the remotes)
- [ ] Check under sofa cushions
- [ ] Each living area done 📸

## Floors (last)
- [ ] Vacuum all carpets and rugs, including under furniture where possible
- [ ] Mop all hard floors, kitchen and bathrooms last

## Before leaving
- [ ] All laundry washed, dried, and either used or folded into the linen cupboard
- [ ] All bins emptied; rubbish taken to outside bins
- [ ] Outdoor area tidy (furniture, BBQ, ashtrays); hot tub checked if applicable 📸
- [ ] Heating set to the host's setting; lights off; windows locked
- [ ] Final check against the reference photos
- [ ] Note supplies running low (for the next visit)
- [ ] Door locked 📸 (front door)
- [ ] Mark the job complete in the app

## Report to FreshTurn straight away if:
- there's damage, a strong smell, pests, or a guest is still there
- anything is broken or not working (Wi-Fi, appliances, heating, hot water)
- something valuable was left behind
